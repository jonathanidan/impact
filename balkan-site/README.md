# וויסקי בלקין: אתר עם תשלום דרך ה-API של מורנינג

## מה יש כאן
- `index.html`: דף הנחיתה. הקונה ממלא כמות ופרטים, וטופס התשלום של מורנינג (אשראי / ביט) נפתח בתוך הדף.
- `thanks.html`: העמוד שמורנינג מחזירה אליו אחרי התשלום (בתוך המסגרת).
- `netlify/functions/`: שלוש פונקציות קטנות שרצות ב-Netlify (חינם):
  - `create-payment`: מחשבת את הסכום בשרת ופותחת תשלום במורנינג עם פרטי הקונה.
  - `morning-notify`: מורנינג מודיעה לה כשהתשלום עבר.
  - `order-status`: מחזירה לדף קישור לקבלה.

## העלאה (פעם אחת, דרך שורת הפקודה)
גרירה ל-Netlify Drop לא מריצה פונקציות, לכן מעלים עם Netlify CLI. צריך Node.js מותקן.

```
cd balkin-site
npm install
npx netlify-cli login
npx netlify-cli link      # בוחרים את האתר הקיים (inquisitive-sunburst-ea893a) או יוצרים חדש
npx netlify-cli deploy --prod
```

## משתני סביבה (Netlify → Site configuration → Environment variables)
| שם | ערך |
|---|---|
| `MORNING_API_ID` | ה-ID של מפתח ה-API |
| `MORNING_API_SECRET` | ה-Secret של המפתח |
| `MORNING_ENV` | `production` (או `sandbox` לחשבון בדיקות) |
| `NOTIFY_KEY` | מחרוזת אקראית ארוכה שתמציאו (מגינה על כתובת ההתראה) |
| `SHOW_DEBUG` | `true` רק בזמן הבדיקה הראשונה, אחר כך למחוק |
| `MORNING_DOC_TYPE` | לא חובה. ברירת מחדל `400` (קבלה, מתאים לעמותה). `320` לחשבונית מס קבלה |
| `MORNING_VAT_TYPE` | לא חובה. ברירת מחדל `1` (המחיר כולל מע״מ). `2` = פטור |
| `MORNING_PLUGIN_ID` | לא חובה. מזהה תוסף הסליקה, אם מורנינג דורשת |
| `ALLOW_TEST_ORDER` | ברירת מחדל: מופעל (0 בקבוקים = תשלום בדיקה של 5 ₪). לפני העלייה לאוויר: `false`, ובדף לשנות `TEST_ORDER = false` |
| `ALLOWED_ORIGINS` | לא חובה. ברירת מחדל: lotar-association.com |

אחרי שינוי משתנים צריך להריץ שוב `npx netlify-cli deploy --prod`.

## בדיקה ראשונה
1. בוחרים 0 בקבוקים (הזמנת בדיקה) ומשלמים 5 ₪ עם הפרטים שלכם.
2. בודקים במורנינג שהקבלה כוללת שם, טלפון, כתובת ומספר הזמנה.
3. מבטלים או מחזירים את העסקה במורנינג.
אם התשלום לא נפתח, עם `SHOW_DEBUG=true` הדף מציג את השגיאה שמורנינג החזירה. אפשר גם לראות אותה ב-Netlify → Logs → Functions.

## הזמנות
כל הזמנה נשמרת ב-Netlify Blobs (מאגר בשם orders) עם מספר הזמנה, פרטי הקונה וסטטוס. המקור המלא לתשלומים ולקבלות הוא מורנינג.
